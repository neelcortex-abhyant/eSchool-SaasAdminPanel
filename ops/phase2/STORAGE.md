# Storage — Phase 2 operational design

## Decision

Laravel and FastAPI serve the **same public media contract**:

- Path shape: `{APP_URL}/storage/...` (Laravel public disk / `storage:link` semantics)
- Shared backing store: NFS/EFS/local volume **or** S3-compatible bucket mounted/mapped identically for both runtimes
- Frozen media origin from [baseline/FROZEN_ORIGINS.md](../../baseline/FROZEN_ORIGINS.md) — never emit temporary FastAPI hostnames in JSON, HTML, emails, notifications, or payment sessions

---

## APP_URL and public URL builder

| Rule | Detail |
| --- | --- |
| Source of truth | Production `APP_URL` (verify against live Laravel config — currently UNVERIFIED in frozen origins) |
| Builder | FastAPI must concatenate `APP_URL.rstrip('/') + '/storage/' + relative_path` exactly as Laravel `Storage::url` / asset helpers do for the public disk |
| Relative paths in DB | Preserve existing DB values (`school/...`, filenames). Do not rewrite historical rows to absolute URLs unless Laravel already stored absolute |
| Canary leak test | Contract suite rejects any response containing staging FastAPI host, `:8001`, or non-frozen media host |

---

## Upload limits and validation (parity)

| Constraint | Value | Notes |
| --- | --- | --- |
| Max upload | **50 MB** | Match PHP `upload_max_filesize` / product UI; also set reverse-proxy `client_max_body_size` |
| MIME / extension checks | Same allow/deny lists as Laravel validators | Block executables (`.php`, `.exe`, `.sh`, etc.) as Laravel does |
| Filenames | Preserve generation scheme (uuid/slug); do not change download names clients already see |
| Thumbnails / transforms | Shared filesystem paths if Laravel writes siblings; FastAPI must find the same files |
| `Content-Disposition` | Parity on download endpoints | Golden-diff headers |
| Student-web timeout | 10s client timeout — large downloads may stream; uploads of 50 MB need proxy/read timeouts ≥ product need (document measured values in baseline) |

Proxy and FastAPI/uvicorn body limits must all allow 50 MB or clients see opaque 413s.

---

## No signed URLs without client release

Flutter and student-web expect ordinary HTTPS `/storage/...` (or absolute URLs built from frozen `APP_URL`).

**Forbidden during this migration:**

- S3 pre-signed URLs as the only access path
- Time-limited query signatures on media URLs returned in API JSON
- CDN token schemes that break existing deep links

If object storage is introduced behind the scenes, put a public CDN/proxy in front that continues to serve unsigned `/storage/...` paths. Any signed-URL strategy requires a separate client release and frozen-origin update.

Transportation **tracking** links are a different contract (signed token + Redis); do not conflate with media URLs. Tracking remains `APP_KEY`-based as today.

---

## Directory / tenancy layout

Preserve Laravel’s school-scoped paths under the public disk (inventory exact prefixes during Phase 3 from upload helpers). Typical patterns to keep stable:

- School logos, student/staff avatars, assignment attachments, gallery, certificates, backup zips, import templates

Backups generated by jobs must land on the **same** shared volume both stacks can read for download/restore.

---

## Serving strategy during canary

| Option | When |
| --- | --- |
| A. Nginx/Apache serves `/storage` from shared volume; both apps only write files | Preferred — fewest moving parts |
| B. Laravel continues to serve `/storage`; FastAPI only writes to shared disk | Acceptable while media host stays frozen |
| C. FastAPI StaticFiles for `/storage` | Only if paths and permissions match byte-for-byte |

Rollback of API routes must not orphan files written by FastAPI — shared disk makes this safe.

## Operational checklist

- [ ] Mount identical path on Laravel and FastAPI hosts
- [ ] `www-data` / app user write permissions verified
- [ ] `php artisan storage:link` equivalent documented for FastAPI deploys
- [ ] Virus/malware scanning policy unchanged (if any)
- [ ] Backup jobs include media volume (see [BACKUP_RESTORE.md](BACKUP_RESTORE.md))
- [ ] 50 MB upload test from Flutter and admin paths before write canary of upload domains

---

## Acceptance pointers

Checksum parity: upload via Laravel, read via FastAPI URL; reverse; 50 MB success; no signed URL in API fixtures.
